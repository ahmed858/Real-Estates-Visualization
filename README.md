# Unit Explorer

Interactive 2D floor plan visualization for real estate projects. Visitors
move from the building facade to a floor to a unit; each unit is coloured by
its live sales status from a spreadsheet.

- Rules for contributors and the hourly agent: [`CLAUDE.md`](CLAUDE.md)
- Architecture: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Roadmap and work units: [`docs/BACKLOG.md`](docs/BACKLOG.md)

```bash
npm ci
npm run dev
npm run check
```
