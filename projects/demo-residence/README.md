# demo-residence

The demo shown to prospects: a real six-storey residential building with
floor overlays drawn on the photo. Facade → 6 floors (ground to fifth) → 4
apartments per floor (A and D: 3 bedrooms, B and C: 2 bedrooms), 24 units
with mixed statuses. Prices and statuses are demo values, and the WhatsApp
number `+201000000000` is a placeholder.

The facade also offers premium views (shown as 3D / 360° shortcuts above the
photo): a 3D model of the building whose floors open their plans, and 360°
panoramas of an apartment A living room, an apartment B master bedroom and
the rooftop.

Unlike `demo-villa`, `project.json` is not generated; edit it directly and
run `npm run validate -- demo-residence`. The premium assets are generated:

```bash
node scripts/demo-residence-premium/generate.mjs            # every asset (about a minute)
node scripts/demo-residence-premium/generate.mjs model      # one job: model, building-poster,
                                                            # floor-outlines, panorama-<view>, poster-<view>
```

It builds the scenes procedurally with three.js in the pre-installed
Chromium (software WebGL): the building from the plan's footprint (31.25 x
20.6 m, ground + 5 floors of 3.2 m, the plan's balcony bays), the rooms from
the typical plan, all textures drawn on a canvas. Renders can differ
slightly between machines, so the files are committed and CI does not
regenerate them. After changing the building, run `floor-outlines` and copy
`scripts/demo-residence-premium/floor-outlines.json` into the `building-3d`
hotspots' `points`.
